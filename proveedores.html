Busqueda de proveedores

Ingrese el RUT de una empresa para verificar si se encuentra inscrita como proveedora del Estado. El RUT se valida con el algoritmo de digito verificador (modulo 11) antes de consultar a Mercado Publico.

Datos de busqueda

Se admite con o sin puntos y guion; el formato se completa automaticamente.

Como se valida el RUT

  1. Se eliminan puntos, guiones y espacios.
  2. Se separa el cuerpo del digito verificador.
  3. Se multiplica cada digito por la serie 2, 3, 4, 5, 6, 7 de derecha a izquierda.
  4. Se calcula 11 menos el resto de la division por 11.
  5. El resultado 11 equivale a 0 y el resultado 10 equivale a K.
